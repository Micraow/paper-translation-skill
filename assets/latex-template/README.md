# XeLaTeX translation project starter

This is a **generic demonstrator**, not a translated scholarly article. Replace every example paragraph, citation, and placeholder with verified source material before distributing an output.

## Compile a working demo

```bash
python3 -m pip install -r requirements.txt   # requirements.txt is at skill root
make                                      # native \cite + \bibitem mode (default)
make render                               # view work/final-render/contact-sheet.png
```

## Practical full-paper coverage (for 500–1000+ source blocks)

```bash
# After placing sources/original.pdf:
cp assets/coverage-map.example.json assets/coverage-map.json
# Open the original PDF page renders first; replace ALL demo heading regexes,
# target files and column_split_x with this paper's REAL structure.
make seed-coverage         # extracts blocks and proposes chapter/asset mappings
```

**Every generated row remains `todo`**, even with suggested targets. The mapping requires each original section heading to match *exactly once*; failed matching blocks the command rather than silently assigning later sections to the wrong chapter. After comparing the source renders to each translated section, confirm the reviewed group:

```bash
python3 scripts/confirm_coverage.py work/coverage.tsv --status translated \
  --target sections/01-introduction.tex \
  --review-note 'Compared every block on source pages 2-3 with translated prose'
```

`make release` stays strict until all meaningful blocks have genuinely been reviewed. See `references/COVERAGE_LEDGER.md` in the skill root. The extracted TSV is a **navigation aid**, not authoritative scientific text; some mathematical fonts map to replacement glyphs.

## Copyable scientific typography

```tex
\qty{5.4}{\micro\second}            % upright scientific unit
5.4\,\us                               % also works in math context
\zhstrong{关键结论}                       % real Chinese emphasis; not italic fallback
\textsc{HPCC}                          % Latin Modern Caps font, no missing sc face

% Crop includes original Algorithm 1 heading (no duplicate caption):
\numberedpreservedalgorithm{figures/alg01.pdf}{alg:hpcc}

% Crop contains only the code body:
\translatedalgorithm{figures/alg01-body.pdf}{发送端伪代码}{alg:hpcc}
% Then use: 算法~\ref{alg:hpcc}
```

`make` rejects literal CJK `\emph{中文}` by default, and checks the LaTeX log for missing italic/small-caps font faces as well as missing characters. That way bold/italic visual information cannot be silently dropped. Only use escape hatches after verifying fonts and visually reviewing the output.

These two algorithm alternatives are mutually exclusive for the **same** algorithm. Do not use a `figure` counter for algorithms or `\caption*` followed by `\label`. Equations should prefer natural automatic numbering; use `\tag{n}` only when necessary and check for `xdvipdfmx` duplicate-destination warnings.

## Two exclusive reference workflows

- `make` / `make BIB_MODE=native`: use `\cite{...}` and source-complete `sections/references.tex` with native `\bibitem` (or correctly configured bibliography source). All links are generated by LaTeX.
- `make BIB_MODE=pdf`: set `\OriginalReferencePages`, put `sources/original.pdf` in place, replace demo `\cite` usages with faithful visible `[n]` markers; original bibliography pages are inserted and `scripts/add_reference_links.py` runs with strict checks automatically. Set `REF_START_PAGE=...` **only** when auto-detection is ambiguous (the value refers to the *compiled final PDF*).

Don't mix native `\cite` with PDF-preserved references: they are different backends. The project linter deliberately catches this mix-up.

## Commands

| Command | Meaning |
|---|---|
| `make` | build + semantic LaTeX checks + PDF/link/log audit |
| `make render` | render all PDF pages and a contact sheet |
| `make source-blocks` | Index the source PDF into a stable block TSV, if source file exists |
| `make seed-coverage` | Propose headings/geometry-based source block mappings (all `todo`) |
| `make release` | additionally validate coverage ledger against extracted source text blocks; render previews |
| `make distclean` | remove generated build outputs; keep sources and translation |

`make release` only automates structural gates. A human/agent must still compare the translation to source, inspect figure crops, and review page renders.
