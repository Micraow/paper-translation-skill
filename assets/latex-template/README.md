# XeLaTeX translation project starter

This is a **generic demonstrator**, not a translated scholarly article. Replace every example paragraph, citation, and placeholder with verified source material before distributing an output.

## Compile a working demo

```bash
python3 -m pip install -r requirements.txt   # requirements.txt is at skill root
make                                      # native \cite + \bibitem mode (default)
make render                               # view work/final-render/contact-sheet.png
```

## Two exclusive reference workflows

- `make` / `make BIB_MODE=native`: use `\cite{...}` and source-complete `sections/references.tex` with native `\bibitem` (or correctly configured bibliography source). All links are generated by LaTeX.
- `make BIB_MODE=pdf`: set `\OriginalReferencePages`, put `sources/original.pdf` in place, replace demo `\cite` usages with faithful visible `[n]` markers; original bibliography pages are inserted and `scripts/add_reference_links.py` runs with strict checks automatically. Set `REF_START_PAGE=...` **only** when auto-detection is ambiguous (the value refers to the *compiled final PDF*).

Don't mix native `\cite` with PDF-preserved references: they are different backends. The project linter deliberately catches this mix-up.

## Commands

| Command | Meaning |
|---|---|
| `make` | build + semantic LaTeX checks + PDF/link/log audit |
| `make render` | render all PDF pages and a contact sheet |
| `make release` | additionally validate coverage ledger against extracted source text blocks; render previews |
| `make distclean` | remove generated build outputs; keep sources and translation |

`make release` only automates structural gates. A human/agent must still compare the translation to source, inspect figure crops, and review page renders.
